# 🚆 IRCTC Backend

A Railway Reservation System backend built using Spring Boot.

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Spring Data JPA
- Gradle

## Features

### ✅ Completed

- User Registration
- Train Management
- Automatic Seat Generation

### 🚧 In Progress

- Booking Module
- Ticket Module

### 🔜 Planned

- JWT Authentication
- Exception Handling
- Validation
- Swagger
- Docker
